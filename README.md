# Gita Verse

The Bhagavad Gita website at [gitaverse.co.in](https://gitaverse.co.in): all 18 chapters and 700 verses with meanings in 74 languages, verse narration, and "Ask Krishna", a guide that answers life questions from the Gita. New accounts get one free Ask Krishna question; Annual Access (₹1,000/year, paid through Razorpay) unlocks the rest.

## Quick start

```bash
# Run the site (no build step; it talks to the live Supabase project)
python3 -m http.server 8000        # open http://localhost:8000

# Unit tests
node --test tests/*.cjs

# Browser tests (simulated backend; nothing touches production)
cd tests/e2e && npm ci && npx playwright install chromium && node run.mjs
```

## Stack

- **Website:** static `index.html` + `app.js` (plain JavaScript) on Vercel. Merging to `main` deploys to production.
- **Backend:** Supabase project `bkwvuckznpaawmqrjjgk` (Postgres, Auth, edge functions in `supabase/functions/`, migrations in `supabase/migrations/`).
- **Providers:** Google Gemini (Ask Krishna, translations), ElevenLabs (narration), Razorpay (payments), MSG91 (sign-in SMS), Meta Pixel (ads).
